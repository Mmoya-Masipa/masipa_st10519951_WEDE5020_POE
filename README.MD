## Project Overview
The Street Store is a non-profit organisation that helps people experiencing homelessness in Johannesburg. They do this by setting up pop-up shops where people can choose clothes with dignity, instead of just being handed bags of clothes. This website is meant to help them find volunteers, get donations, and share their events.

## Website Goals and Objectives
- Get more volunteers to sign up.
- Get more clothing donations.
- Get corporate sponsorships.

## Key Features and Functionality
- Navigation menu on all pages.
- Big hero image with buttons to Volunteer and Donate.
- Responsive design so it works on phones and laptops.
- Forms for people to contact us or sign up.
