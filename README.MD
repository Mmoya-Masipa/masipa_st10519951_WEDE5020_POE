## Project Overview
The Street Store is a non-profit organisation based in Johannesburg that restores dignity to people experiencing homelessness through compassionate, retail-style clothing distribution. This website serves as a digital hub for volunteer recruitment, donor engagement, and event promotion, allowing users to browse upcoming events and sign up to help.

## Website Goals and Objectives
- Increase volunteer registrations (target 50 per month).
- Increase clothing donations (target 1,000 items per month).
- Secure 5 corporate sponsorships in 6 months.
- Establish credibility and streamline engagement.

## Key Features and Functionality
- **Responsive Design:** Fully responsive layout that adapts seamlessly to desktop, tablet, and mobile devices.
- **Mobile Navigation:** A JavaScript-powered hamburger menu for mobile users.
- **Interactive Forms:** Contact and volunteer sign-up forms with HTML5 validation.
- **Clear CTAs:** Prominent call-to-action buttons (Volunteer Now, Donate) on the homepage.
